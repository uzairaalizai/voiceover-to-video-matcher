# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-09

### Added
- Initial release of Voiceover to Video Matcher
- Audio extraction and transcription from video files
- Audio segmentation into narration sentences
- Video frame extraction with configurable sampling
- Visual content analysis using AI (GPT-4 Vision)
- Semantic matching between narration and visual content
- Confidence scoring and result ranking
- Command-line interface (CLI) with multiple commands
- Python API for programmatic usage
- Comprehensive configuration system via .env
- Logging system with file and console output
- Unit tests and integration tests
- Full API documentation
- Usage examples for common scenarios
- Support for multiple media formats:
  - Video: MP4, MOV, WebM, AVI, MKV, FLV
  - Images: JPG, PNG, GIF, BMP, WebP
  - Audio: MP3, WAV, AAC, FLAC, M4A

### Features
- Automatic audio-to-visual matching
- Semantic embedding-based similarity calculation
- Temporal proximity scoring
- Batch processing support
- JSON output format
- Configurable confidence thresholds
- Frame sampling for performance optimization
